Open-source image flasher from Pantacor

Write only the blocks that hold data. Then check every one.

pvflasher puts OS images on SD cards and USB drives. It follows the image's .bmap to skip empty space, decompresses while it writes, and reads the card back before it tells you it's done.

Benchmark

Verified in 33.5 seconds.

With verification on, pvflasher writes the image and reads every written block back faster than Raspberry Pi Imager writes it without checking. It is 1.8× faster than dd and on par with bmaptool, which never reads the card back.

Pantavisor 030 rpi-scarthgap image: 390 MB compressed, 715 MB raw, 504 MB mapped. microSD card in a USB 3 reader, cold page cache, mean of two runs. Raw results · Run it yourself

Why pvflasher

Fast because it does less. Safe because it checks.

Writes only the data

When a .bmap sits next to the image, pvflasher writes the mapped blocks and skips the rest. On the benchmark image that is 30% less to write. pvflasher create makes a block map for any raw image.

Flashes straight from the archive

.gz, .bz2, .xz, .zst and .zip are decompressed in parallel with the writes. No unpacking step and no temporary copy of the image.

Reads the card back

Every written block is read from the card and checked against its SHA-256 checksum. A failed write, a worn card or a fake-capacity card shows up before you boot the board.

Keeps away from your system disk

The app only offers removable drives. Internal disks, drives in use by the system and empty card readers never appear, and you confirm before anything is erased.

Pantavisor releases built in

Pick a channel, version and device with the same names as pantavisor.io. The image is downloaded, checksum-validated, cached and flashed in one go.

Keeps itself up to date

The app checks for a release once a day. Updates install only when their minisign signature matches the release key built into pvflasher.

How it works

Three steps, one window.

  1. 1Pick an image

    Choose a file, drop one on the window, or pick an official Pantavisor release.

  2. 2Choose the drive and flash

    The drive list refreshes as you plug cards in. Confirm, and pvflasher asks for administrator rights only when it starts writing.

  3. 3Done and verified

    The card is checked, ejected and ready for your board.

Made by Pantacor

From the team that builds Pantavisor.

Pantavisor is the container-based init system for embedded Linux. pvflasher works with images from any distribution, and its desktop app and CLI have a dedicated flow for Pantavisor releases.

pvflasher CLI
# list drives
$ pvflasher list
Available devices:
- /dev/sda: GoPro Quik_Key (Removable)  [31914983424 bytes]

# flash, using the .bmap next to the image
$ pvflasher copy ubuntu-24.04.img.xz /dev/sda

# pick and flash an official Pantavisor release
$ pvflasher install
